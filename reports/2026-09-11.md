# TradeBinder Health Report — 2026-09-11

First report — no prior baseline, so everything below is new.

## Needs attention

1. **Next.js critical security advisories — `package.json`**
   Installed `next@16.2.5`. `npm audit` flags a **critical** issue (middleware/proxy bypass, plus SSRF, cache-confusion, and an unauthenticated RCE on Windows hosts in the same version range) plus several **high** ones. All are fixed in `16.3.4`, which is still within the existing `^16.0.0` range in `package.json` — a normal `npm install` / lockfile bump resolves it, no code changes needed. Worth doing soon since this is the live app's framework.

2. **`user_cards` table has no migration — `supabase/migrations/`**
   The app's core "owned cards" feature (`app/collection/useCollection.ts`, `useCollectionDashboard.ts`, `app/binder/useBinder.ts`, `app/trade/page.tsx`, `app/profile/ProfileView.tsx`) reads/writes `user_cards`, and migrations 008/009 `ALTER`/`UPDATE` it — but no migration file ever `CREATE TABLE`s it. Anyone following the README's "apply migrations in order" on a fresh Supabase project gets a broken app. Either the original create statement was applied by hand and never captured, or a migration file is missing — worth adding a migration (or a comment in the README) so setup is reproducible.

3. **`postcss` has known advisories — `package.json` (devDependency)**
   Installed `8.5.10`; advisories (XSS in stringify output, source-map path traversal/file disclosure) are fixed by `8.5.28`, still a minor-version bump. Lower risk than #1 (build-time only) but a one-line fix.

## Fine / no change

Build passes clean (`next build`, 14 routes, no TS errors). Only `main` branch exists, nothing unmerged. No TODO/FIXME or commented-out dead code found. Three files are already large and worth knowing about if touching them soon: `app/trade/page.tsx` (1419 lines), `app/inbox/[conversationId]/page.tsx` (951), `app/navbar.tsx` (831) — not urgent, just noting the size. TypeScript (5.9→7.0) and ESLint (9→10) have major versions available but nothing forces an upgrade yet.
