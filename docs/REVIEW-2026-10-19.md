# TradeBinder review: 2026-10-19

Based on Borty's feedback and a read of the code on `main`. Not a full QA pass. Anything marked *(unverified)* is from reading code only.

## Done in this branch
- **"Failed to load sets" fixed.** Cause: `/api/pokemon/sets` and `/cards` sent `Cache-Control: public, s-maxage=3600` even on error responses, so Cloudflare's CDN cached an upstream failure for an hour. A hard refresh bypasses the CDN, which is why that "fixed it".
  - Errors are now `no-store`. Only successes are cached.
  - If the upstream fails, the last good copy is served.
  - There is an 8s upstream timeout.
  - The 4 client call sites retry with backoff (`lib/fetchSets.ts`).
- **Wishlist built** (see below). Needs migration `018_wishlist.sql` applied before it works on prod.

## Known risk
- The Pokémon TCG API is deprecated. Keys stop working **2027-03-01**. It also returns 5xx often. Plan the move to Scrydex (or similar) before then. All upstream access goes through `lib/pokemonServer.ts`, so the swap is one file plus response mapping.

## Visual upgrade: pick one direction

Today: near-black background, one accent colour (emerald, with a blue/rose/amber switcher), glass-morphism cards with big rounded corners, system font (Trebuchet). It's tidy but flat; nothing says "cards".

**Recommended direction: "Binder & Holo".** Feels like a real card binder, no official Pokémon branding or logos.
1. **Card-first surfaces.** Show cards as real card shapes (2.5:3.5 ratio, rounded corners, thin border). Owned cards get a subtle holo-foil sheen on hover/tilt. Unowned cards are dimmed and desaturated. This alone changes the feel of Collection, Binder and Tradeboard.
2. **Binder-page layout.** Set progress shown as a binder spine / page tabs, with a progress ring and "12 to go" per set. Gives collecting a goal to chase.
3. **Type-colour accents + display font.** Use the 18 TCG type colours (fire, water, grass...) as accents per card and set (instead of one global emerald), and a bold display font for headings (e.g. Fredoka or Bricolage Grotesque) with a clean body font.

Alternatives, if "Binder & Holo" isn't it:
- **"Shop counter":** warm, paper and wood, price-tag stickers. Fits the local-shop idea.
- **"Arcade":** dark with neon outlines and pixel accents. Fun, but riskier for readability.
